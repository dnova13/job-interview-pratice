# 면접 연습 (InterviewPractice)

React + Vite + Electron으로 만든 면접 연습용 데스크톱 앱입니다. 카메라로 자신을 보면서 질의에 답하고, 답변을 음성(.m4a)이나 영상(.mp4)으로 녹음해 다시 들으며 검토합니다.

## 주요 기능

- **면접 주제 관리**: 주제마다 제목, 설명, 질의 목록을 둡니다. 질의는 한 줄에 하나씩 붙여넣으면 됩니다.
- **연습 흐름**: 시작 → 전체 화면 대기 카운트 → 질문 표시와 카메라 화면 → 자동 녹음(REC 표시)
- **질의 목록과 학습 기록**: 질의마다 중요도(별 5개), 메모, "안 외워짐" 표시를 남기고, 필터로 골라 선택한 질의만 연습합니다.
- **답변 분석 (참고용)**: 목소리 톤·크기·침묵, 시선(정면 응시), 고개 끄덕임·흔들림을 내 컴퓨터 안에서 측정해 점수와 조언을 보여 줍니다.
- **다시 듣기**: 녹음을 완료하면 카메라 화면 아래쪽에 재생 컨트롤이 나타나(영상과 같은 위치) 원할 때 재생해 검토하고(자동 재생 없음, 다른 질의로 넘어가면 멈춤), 녹음 버튼으로 같은 질의를 다시 연습합니다.
- **자동 / 수동 저장**: 녹음 완료 시 자동으로 저장하거나, 다시 들어 보고 원하는 녹음만 직접 저장합니다.
- **단축키 변경**: 녹음 완료, 정지, 질의 이동, 영상/음성 이동 키를 모두 바꿀 수 있습니다.

## 사용법

1. 홈 화면 오른쪽 위의 **+ 주제 추가**를 눌러 주제를 만듭니다.
   - 제목, 설명, 질의 목록(줄바꿈으로 구분, 빈 줄은 무시)을 입력합니다.
   - 오른쪽 **개별 설정**에서 연습 방식을 정합니다.
2. 주제 카드의 **전체 시작**을 누르면 모든 질의로 연습을 시작합니다. 카드를 누르거나 **질의 목록**을 누르면 질의 목록 화면이 열립니다.
3. 대기 카운트 후 첫 질의와 함께 녹음이 시작되고, 화면 아래 버튼이나 단축키로 진행합니다.

### 질의 목록 화면

| 기능 | 설명 |
|---|---|
| ★ 중요도 | 별 1~5개로 표시합니다. 같은 별을 다시 누르면 해제됩니다. |
| 🚩 안 외워짐 | 잘 안 외워지는 질의를 표시합니다. |
| ✏️ 메모 | 메모 버튼을 누르면 오른쪽 패널에 메모가 보이고, **수정** / **메모 추가**로 고칩니다. 입력하면 자동 저장됩니다. 메모가 있는 질의는 버튼이 파란색입니다. |
| 필터 | 중요도 ★5~★1·미지정(여러 개 선택 가능), 안 외워짐, 메모 있음, 질의·메모 검색 |
| 선택 연습 | 질의를 체크(또는 "보이는 N개 전체 선택")하고, 순서대로/무작위 아이콘을 고른 뒤 **선택한 질의 연습**을 누릅니다. |

연습을 마치고 나오면 질의 목록 화면으로 돌아오며, 필터와 선택은 그대로 남아 있어 다시 골라 연습할 수 있습니다.

### 연습 화면

| 버튼 | 동작 |
|---|---|
| ⏮ 이전 / ⏭ 다음 | 이전·다음 질의로 이동합니다. 녹음 중이면 녹음을 끝내고 이동하며, 자동 저장이면 저장합니다. 이동한 질의는 대기 카운트 후 녹음을 시작합니다. |
| ⏺ 녹음 | 녹음 중에는 **녹음 중**으로 표시되고, 누르면 녹음이 완료됩니다. 다시 듣기 상태에서 누르면 같은 질의를 다시 녹음합니다. 단축키(`Enter`)도 같은 동작을 합니다. |
| ⏸ 정지 | 녹음을 일시정지합니다. 다시 누르면 이어서 녹음합니다. |
| 💾 저장 | 수동 저장 모드의 다시 듣기 화면에만 나옵니다. 이미 저장한 녹음이면 "이미 저장되었습니다"라고 안내합니다. |

질문 영역:

- **★ 중요도 / 🚩 안 외워짐**: 질문 번호 오른쪽에 있으며, 녹음·녹화 중이나 다시 듣기 중에도 바로 표시할 수 있습니다.
- **메모**: 답변을 마친 뒤(다시 듣기)에만 질문 아래에 보입니다. **수정** / **메모 추가**로 그 자리에서 고칠 수 있습니다. 메모를 입력하는 동안에는 단축키가 동작하지 않습니다.

화면 위의 버튼:

- **질의 목록**: 이번 연습의 질의 순서를 보여 줍니다. 항목을 누르면 그 질의로 이동합니다(녹음 중이면 저장 규칙대로 마무리한 뒤 이동). 여기서도 중요도와 안 외워짐 표시를 바꿀 수 있습니다.
- **처음부터 다시**: 순서를 새로 정해 첫 질의부터 다시 연습합니다. 다른 질의를 고르려면 ✕로 나가서 질의 목록에서 다시 선택합니다.

마지막 질의에서 **다음**을 누르면 종료 화면이 나옵니다. 저장 폴더 열기, 처음부터 다시, 목록으로 가기를 고를 수 있습니다.

## 답변 분석 (참고용)

녹음하는 동안 카메라·마이크를 분석해, 녹음을 완료하면 다시 듣기 화면에 결과를 보여 줍니다. 모든 처리는 이 컴퓨터 안에서 하며 외부로 보내지 않습니다.

> 점수는 **나쁜 습관을 찾기 위한 참고용**입니다. "단조로운 목소리, 시선 회피, 과한 고개 움직임은 좋지 않다"는 방향은 연구·코칭 관행에 근거하지만, 숫자 기준은 대부분 경험치입니다. 절대 점수보다 같은 질의의 점수 추이를 보세요. 자세한 기준은 [docs/phase1-analysis-plan.md](docs/phase1-analysis-plan.md)에 있습니다.

| 위치 | 내용 |
|---|---|
| 대기 카운트 | "카메라 렌즈를 보세요" 안내. 이때의 자세를 정면 기준으로, 방 소음을 목소리 기준으로 잡습니다. |
| 녹음 중 | 카메라 위에 눈동자 점과 시선 점(정면 초록, 이탈 주황), 정면 여부, 끄덕임 횟수 |
| 다시 듣기 | 종합 점수와 지난번 대비 변화, 항목별 점수(목소리·말의 흐름·시선·자세)와 실제 측정값·기준, 조언 2~3개 |
| 시선·자세 그림 | 면접관(카메라) 그림 위에 내가 본 위치를 점으로 표시하고 위·아래·왼쪽·오른쪽 비율을 보여 줌(점을 누르면 그 장면으로 이동). 자세는 정면(기울기)·옆모습(끄덕임)·위에서 본 모습(좌우 흔들림) 머리 그림으로 움직인 범위를 표시 |
| 자세히 · 타임라인 | 시선 정면/이탈 띠, 음 높이, 긴 침묵, 끄덕임 시점. 누르면 그 장면으로 재생 이동. 영상은 재생 중에도 시선 점이 표시됩니다. |
| 질의 목록 | 질의별 최근 점수. 점수를 누르면 오른쪽에 **이전 기록**(최근 순, 10개씩 페이지)이 열리고, 기록을 누르면 상세 보기. 점수 낮은 순/높은 순 정렬 |
| 상세 보기 | 저장한 녹음 파일이 있으면 재생기와 타임라인(영상은 시선 점까지)을, 없으면 점수·그림 등 기록만 표시 |
| 종료 화면 (결과 보고서) | 이번 세션의 종합 점수, 항목별 평균, 반복된 습관. 아래 **상세**에 질의별 항목 점수 비교(누르면 상세 보기), 세션 전체 지표(측정값·기준), 답변을 합친 시선·자세 그림 |
| 종합 기록 | 질의 목록 화면 위쪽 **종합 기록** 버튼. 세션별 종합 점수 목록(10개씩 페이지). 도중에 나간 세션도 "중단"으로 남음. 누르면 종료 화면과 같은 결과 보고서(상세 포함)를 보여 줌 |

- 기록 보관: 질의별 점수는 최근 100회, 상세 데이터(그림·타임라인)는 최근 30회, 종합 기록은 최근 100회까지 남깁니다. 상세 데이터는 `~/Library/Application Support/InterviewPractice/analysis/`에 저장됩니다.
- 주제 설정의 **최소 녹화/녹음 시간** 이하인 답변은 저장하지 않는 것과 같은 기준으로 점수도 내지 않습니다. 얼굴이 잘 잡히지 않으면 시선·자세는 "측정 불가"로 두고 목소리만 점수에 넣습니다.
- 얼굴 분석은 Google MediaPipe Face Landmarker를 씁니다. 일반 노트북의 내장 그래픽으로 충분하며, GPU 모드가 안 되면 CPU 모드로 자동 전환합니다. WebGL2를 쓸 수 없는 환경에서는 목소리만 분석합니다.
- 공통 설정에서 분석과 실시간 표시를 각각 끌 수 있습니다. "고개 각도·측정 횟수 표시"를 켜면 카메라 위에 현재 상하·좌우·기울기 각도와 초당 측정 횟수가 보여 기준(끄덕임 4°)을 확인할 수 있습니다.

## 단축키 (기본값)

| 동작 | 키 |
|---|---|
| 녹음 완료 / 다시 녹음 | `Enter` (녹음 중이면 완료, 다시 듣기 중이면 같은 질의 다시 녹음) |
| 정지 / 재개 | `Space` |
| 이전 질의 / 다음 질의 | `←` / `→` |
| 영상/음성 뒤로 이동 / 앞으로 이동 (다시 듣기) | `Shift + ←` / `Shift + →` |

모든 단축키와 영상/음성 이동 간격(기본 1초)은 **공통 설정**에서 바꿀 수 있습니다.

## 설정

### 개별 설정 (주제마다)

| 항목 | 기본값 | 설명 |
|---|---|---|
| 출제 순서 | 무작위 | 무작위 / 순서대로. 무작위는 세션을 시작할 때 한 번만 섞으므로 이전 질의로 돌아갈 수 있습니다. |
| 대기 카운트 | 5초 | 질의마다 녹음 전에 전체 화면으로 카운트다운합니다. 0이면 바로 녹음합니다. |
| 최소 녹화/녹음 시간 | 10초 | 이 시간 이하로 녹화·녹음되면(영상·음성 모두) 저장하지 않고 답변 분석 점수도 내지 않습니다. 자동 저장과 수동 저장 모두 적용됩니다. |
| 녹음 완료 시 자동 저장 | 켬 | 끄면 수동 저장 모드가 되어 다시 듣기 화면의 저장 버튼으로 저장합니다. |
| 녹음 형식 | 영상 (.mp4) | 영상 (.mp4) / 음성 (.m4a). 연습 화면에는 어느 쪽이든 카메라가 보입니다. |

### 공통 설정 (홈 화면의 설정)

- 녹음 파일 저장 폴더 (기본 `~/Documents/InterviewPractice`)
- 단축키
- 영상/음성 이동 간격 (초)
- 답변 분석 사용, 녹음 중 시선 점·정면 표시

## 저장 규칙

```
{저장 폴더}/
 └─ {주제이름}/
     └─ {주제이름 yymmdd (n)}/          ← 연습 세션마다 하나, 같은 날이면 n 증가
         ├─ {질의 앞 12자} (1).m4a
         ├─ {질의 앞 12자} (2).mp4      ← 같은 질의를 다시 저장하면 n 증가
         └─ ...
```

- 폴더는 **첫 녹음 파일을 저장할 때** 만들어집니다. 저장한 파일이 없으면 폴더도 생기지 않습니다.
- 질의가 12자를 넘으면 앞 12자만 사용합니다.
- 파일 이름에 쓸 수 없는 문자(`/ \ : * ? " < > |`)는 지웁니다.
- 질의별 중요도·메모·안 외워짐 기록은 질의 문장을 기준으로 저장되므로, 질의 문장을 고치면 그 질의의 기록은 사라집니다.
- 주제·설정 데이터는 `~/Library/Application Support/InterviewPractice/store.json`에 저장됩니다.

## 개발

```bash
npm install
npm run dev        # 개발 모드 (Vite + Electron 자동 실행)
npm run typecheck  # 타입 검사
npm run build      # 타입 검사 + 빌드 (dist/, dist-electron/)
npm run preview    # 빌드 후 Electron으로 실행
npm test           # 분석 지표·점수 단위 테스트 (Vitest)
```

`npm run dev` / `npm run build` 전에 `scripts/prepare-mediapipe.mjs`가 MediaPipe wasm을 `public/mediapipe/wasm`으로 복사합니다(저장소에는 올리지 않음). 얼굴 모델 `public/mediapipe/face_landmarker.task`는 저장소에 포함되어 있고, 없으면 내려받습니다.

처음 연습을 시작하면 macOS가 카메라·마이크 권한을 묻습니다. 거부했다면 **시스템 설정 → 개인정보 보호 및 보안**에서 허용해야 합니다.

## 패키징 (electron-builder)

```bash
npm run dist:mac        # macOS .dmg / .zip (arm64 + x64)
npm run dist:mac:local  # 설치 파일 없이 .app만 빠르게 생성
npm run dist:win        # Windows 설치 파일 (.exe, NSIS)
```

- 결과물은 `release/{버전}/`에 생깁니다.
- 설정 파일은 `electron-builder.yml`, macOS 권한 파일은 `build/entitlements.mac.plist`입니다.
- 카메라·마이크 권한 안내 문구(`NSCameraUsageDescription`, `NSMicrophoneUsageDescription`)가 Info.plist에 들어갑니다.
- 기본은 **ad-hoc 서명**이라 이 Mac에서는 바로 실행됩니다.
  - 다른 Mac에 설치하면 Gatekeeper 경고가 뜹니다. 우클릭 → **열기**로 실행해야 합니다.
  - 정식으로 배포하려면 Developer ID 인증서로 서명하고 공증을 받아야 합니다. `electron-builder.yml`의 `identity: "-"` 줄을 지우면 키체인의 인증서로 서명합니다.
- 앱 아이콘은 `build/icon.icns`(macOS), `build/icon.ico`(Windows)를 넣으면 자동으로 쓰입니다.

### GitHub Actions로 자동 릴리스

`.github/workflows/release.yml`이 **main에 푸시할 때마다** macOS·Windows 설치 파일을 만들어 GitHub Releases에 올립니다. 태그나 버전 번호는 직접 다룰 필요가 없습니다.

- 버전은 자동으로 정해집니다: `package.json`의 주·부 번호 + 워크플로 실행 번호 (예: `0.1.17`). 태그(`v0.1.17`)와 Release도 워크플로가 만듭니다.
- 큰 변경으로 버전을 올리고 싶을 때만 `package.json`의 주·부 번호를 고칩니다(예: `0.2.0`). 끝자리는 무시됩니다.
- 문서(`.md`, `docs/`)만 바뀐 푸시는 건너뜁니다. 연달아 푸시하면 마지막 것만 릴리스합니다.
- 테스트(`npm test`)를 통과해야 패키징합니다.
- 결과물: `.dmg`·`.zip`(mac arm64·x64), `.exe`(Windows). 릴리스 노트는 커밋 목록으로 자동 생성됩니다.
- Actions 탭의 **Run workflow**로 직접 실행해도 같은 방식으로 릴리스합니다.
- 비공개 저장소의 릴리스는 저장소 접근 권한이 있는 사람만 받을 수 있습니다.
- 서명은 로컬과 같은 ad-hoc이라 받은 Mac에서는 Gatekeeper 경고, Windows에서는 SmartScreen 경고가 뜹니다.
